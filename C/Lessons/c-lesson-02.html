Variables & Data Types

Every piece of data your program touches lives somewhere in memory. Variables are how you name that memory and control what goes into it.

Beginner ~25 min 1 exercise
01 — What is a variable

A named box in memory

Your computer has RAM — billions of tiny storage cells, each holding one byte of data. A variable is simply a named label you stick on one or more of those cells so you can find and use the value later.

In C, before you can use a variable, you must declare it. That declaration does two things: it gives the variable a name, and it tells the compiler how much memory to reserve and what kind of data will go there.

declaration syntax 
int age;            // declare only — value is garbage until set
int age = 20;        // declare and initialise in one line
age = 21;            // assign a new value later
⚠️
Never use an uninitialised variable. If you declare int age; and read it before assigning a value, you get whatever random bytes happened to be in that memory slot. This is a very common source of bugs in C.
02 — Data types & memory

Why types matter — it's all about bytes

Rule of thumb: Use int for whole numbers, double for decimals. Only switch to float or smaller types when memory is a real constraint (embedded systems, large arrays). For most university work, int and double will cover 90% of cases.
03 — Naming rules

What you can and cannot name a variable

C is strict about variable names. Break these rules and the compiler refuses to build your program.

  • ✓ Must start with a letter or underscore — age, _count, totalScore are all valid.
  • ✓ Can contain letters, digits, and underscores after the first character — score2, first_name.
  • ✗ Cannot start with a digit — 2score is illegal.
  • ✗ Cannot use spaces or special characters — my score and my-score are illegal.
  • ✗ Cannot use C reserved keywords — int, return, if, while, etc. are off-limits as variable names.
  • ✗ C is case-sensitive. Age, age, and AGE are three completely different variables.
💡
Convention: C programmers use snake_case for variable names — all lowercase, words separated by underscores. Example: total_score, student_age. You will see this throughout all real C code.
04 — Constants

Values that should never change

Sometimes you have a value that must stay fixed for the entire program — like PI, or the maximum size of an array. C gives you two ways to define constants:

#define PI 3.14159
Preprocessor macro. Before compilation, every occurrence of PI is text-replaced with 3.14159. No memory is allocated. Has no type.
const double PI = 3.14159;
Type-safe constant. Allocates memory like a normal variable but the compiler prevents any reassignment. Preferred in modern C.
✅
Best practice: Prefer const over #define. With const, the compiler knows the type, can catch mistakes, and debuggers can see the name. With #define, the name disappears before compilation — it's just a blind text substitution.
05 — Putting it together

A complete working program

Read this carefully. Every variable is declared with a type, initialised before use, and printed with the correct format specifier.

variables.c 
#include <stdio.h>

#define MAX_SCORE 100

int main() {

    // Integer variables
    int age = 20;
    int score = 87;

    // Decimal variables
    double gpa = 3.75;
    float  temperature = 36.6f;  // 'f' suffix marks a float literal

    // Character variable
    char grade = 'A';             // single quotes for char, not double

    // Constant
    const double PI = 3.14159;

    // Print them all
    printf("Age:         %d\n", age);
    printf("Score:       %d / %d\n", score, MAX_SCORE);
    printf("GPA:         %.2lf\n", gpa);
    printf("Temperature: %.1ff\n", temperature);
    printf("Grade:       %c\n", grade);
    printf("PI:          %.5lf\n", PI);

    return 0;
}

Expected output when you run this:

output 
Age:         20
Score:       87 / 100
GPA:         3.75
Temperature: 36.6f
Grade:       A
PI:          3.14159
'A' vs "A"
Single quotes are for char (one character). Double quotes are for strings (text). Using double quotes for a char is a common mistake.
36.6f
The f suffix tells the compiler this is a float literal, not a double. Without it, 36.6 is treated as a double by default.
%.2lf
The .2 controls decimal precision. %.2lf prints exactly 2 decimal places. %.5lf prints 5.
06 — Common mistakes

Errors beginners make with variables

mistakes.c — study these before writing your own code 
// MISTAKE 1 — wrong format specifier
double gpa = 3.75;
printf("%d\n", gpa);   // ✗ %d is for int — output will be garbage
printf("%lf\n", gpa);  // ✓ correct

// MISTAKE 2 — assigning to a const
const int MAX = 100;
MAX = 200;              // ✗ compiler error: assignment of read-only variable

// MISTAKE 3 — integer division when you expect decimals
int a = 5, b = 2;
double result = a / b;  // ✗ result is 2.0, not 2.5 — int/int = int
double result = (double)a / b; // ✓ cast a to double first

// MISTAKE 4 — using double quotes for a char
char grade = "A";  // ✗ "A" is a string, not a char
char grade = 'A';  // ✓ single quotes
🔴
Mistake 3 is the trickiest. In C, dividing two integers always gives an integer — the decimal part is thrown away silently. 5 / 2 gives 2, not 2.5. To get the decimal result, cast at least one operand to double first: (double)a / b.
