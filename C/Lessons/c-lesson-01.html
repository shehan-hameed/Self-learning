Introduction & How C Works

Before writing a single line of code, you need to understand what actually happens when you run a C program. Most beginners skip this — and regret it later.

Beginner ~20 min 1 exercise
01 — What is C

A language that talks directly to hardware

C was created by Dennis Ritchie in 1972 at Bell Labs, originally to build the UNIX operating system. It became one of the most influential languages ever written — Python, Java, JavaScript, and even C++ are all descended from it.

The key thing that makes C different from languages you may have heard of is that it is a compiled language. You write human-readable code, and a program called the compiler translates it into binary machine code that your CPU runs directly. There is no middleman at runtime.

Compiled
Your code is translated to machine code before running. Errors are caught at compile time, not at runtime.
Low-level
C gives you direct control over memory. You decide what is stored where. Great power, great responsibility.
Statically typed
Every variable must have a type declared upfront. The compiler enforces this at compile time.
02 — The compilation pipeline

What happens when you "run" a C program

You never directly run a .c file. Four steps happen first:

Step 1 — Preprocessor: Handles all lines starting with #. When it sees #include <stdio.h>, it literally copy-pastes that header file into your code before compilation.

Step 2 — Compiler: Reads your C code, checks for syntax errors, and translates it into machine code. If you forgot a semicolon, it stops here and tells you.

Step 3 — Linker: Connects your code with library code (like the code behind printf) to produce the final executable.

Step 4 — Execution: Your OS loads the executable and the CPU runs it directly. No interpreter involved.

03 — Your first program

Hello, World — every line explained

This is the most famous program in all of programming. Do not skim it. Every character matters.

hello.c 
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}

Now let's go line by line:

#include <stdio.h>
Tells the preprocessor to pull in the Standard Input/Output library. Without this, printf does not exist.
int main() {
Every C program must have a main function. Execution starts here. int means it returns an integer to the OS.
printf("Hello, World!\n");
Prints text to the screen. \n is the newline escape — it moves the cursor to the next line. The ; ends the statement.
return 0;
Tells the OS the program finished successfully. By convention, 0 = success, anything else = error.
}
Closes the main function body. Every { must have a matching }.
⚠️
The #1 beginner mistake: Forgetting the semicolon ; at the end of a statement. The compiler will stop and throw an error every time. Treat semicolons like the period at the end of a sentence — mandatory.
04 — Errors you will encounter

Three types of errors in C

Your college notes mentioned these. Let's make them concrete with real examples.

Syntax error
Violates C grammar. The compiler catches this and refuses to compile. Example: missing ; or mismatched braces {}.
Semantic error
Code runs but produces wrong results. Example: writing a - b when you meant a + b. The compiler cannot catch this.
Runtime error
Happens while the program is running. Example: dividing by zero, or accessing memory you do not own. The program crashes.
syntax_error_example.c — this will NOT compile 
#include <stdio.h>

int main() {
    printf("Hello")  // ← missing semicolon — compiler stops here
    return 0;
}
